# Generated tree - do not hand-edit

`plugins/zcode-charter-kit/` is produced by `python scripts/build_zcode_plugin.py`. Every build replaces
this tree, so an edit made here is deleted rather than merged, and nothing
reports the loss.

Edit `targets/zcode/` instead, then regenerate:

```text
python scripts/build_zcode_plugin.py
```

The Skill tree, the slash command, and the manifest are copied from that target; the portable core and the root-level files are copied from the repository root.

`docs/MIRROR-TOPOLOGY.md` maps every copy in this repository to the tree an
edit survives in.
