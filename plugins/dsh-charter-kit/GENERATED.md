# Generated tree - do not hand-edit

`plugins/dsh-charter-kit/` is produced by `python scripts/build_dsh_plugin.py`. Every build replaces
this tree, so an edit made here is deleted rather than merged, and nothing
reports the loss.

Edit `targets/dsh/` instead, then regenerate:

```text
python scripts/build_dsh_plugin.py
```

The adapter files are copied from that target. The Skill tree is copied from the repository-root `skills/charter-workflow/`, which is itself generated by `python scripts/build_codex_plugin.py`, so run the Codex builder first.

`docs/MIRROR-TOPOLOGY.md` maps every copy in this repository to the tree an
edit survives in.
